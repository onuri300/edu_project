## 메뉴 탐색과 검증

- 원본의 Site Map 전체 메뉴 기능은 공원의 **전체 어트랙션**에서 제공합니다.
- 원본 파일 및 앵커를 대조한 테마 구역은 5개, 어트랙션은 33개입니다.
- 중복을 합친 원본 페이지 28개에서 HTTP 200을 확인했습니다. 원본의 계정별 메뉴 표시와 로그인 이후 본문은 운영 환경에서 달라질 수 있습니다.
- 원본 사이트는 https://onuri300.github.io/edu_project/ 입니다. 표의 파일 경로는 이 주소를 기준으로 합니다.
