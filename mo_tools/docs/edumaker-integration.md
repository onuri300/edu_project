# edumaker 연결 및 소스 보관

수업 자료실 → edumaker 메뉴는 `cl_class/cl_edumkr.html`을 엽니다.
페이지의 ‘edumaker 열기’는 기존 운영 서비스인 [메이킹 수업 스튜디오](https://making-class-studio.spry-mochi-7529.chatgpt.site)를 새 탭으로 엽니다.
Sites의 현재 서비스 주소와 active 상태를 확인했습니다. 실제 앱 로그인·AI 생성·저장은 이번 작업에서 호출하지 않았습니다.

## 소스

- 원본: `D:/project/edumaker` — 변경하지 않았습니다.
- 이 프로젝트의 사본: `common/apps/edumaker`
- 원본의 앱 코드·UI·공개 자산·DB 스키마·마이그레이션·테스트·실행 스크립트·잠금 파일·가이드를 복사했습니다.
- 실제 환경변수, API 키 파일, `.dev.vars`, `.env`, DB 저장 데이터, 로그인 쿠키, 의존성, 캐시와 빌드 결과는 제외했습니다.
- 소스 사본은 공개 Pages 배포 대상에 포함하지 않습니다.

edumaker는 React/Vinext·Cloudflare Workers·D1을 쓰는 서버 앱입니다. GitHub Pages의 정적 HTML 폴더에서 해당 서버 기능을 실행할 수 없습니다.
현재 메뉴는 기존 운영 서비스를 연결하며, 복사한 최신 로컬 소스를 온라인 서비스에 새로 배포하지는 않았습니다. 기존 운영 데이터·공유 설정도 변경하지 않았습니다.
소스 개발을 이어갈 때는 사본의 AGENTS.md, START_HERE_KO.md, CODEX_HANDOFF.md를 먼저 읽고 별도 앱으로 실행·검증하세요.
기존 운영 서비스와 로컬 원본은 저장 데이터와 배포 버전이 다를 수 있습니다.
