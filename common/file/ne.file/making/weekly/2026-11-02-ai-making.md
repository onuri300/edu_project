# 주간 AI·디지털 메이킹 통합 리포트

대상: 2026-10-26~2026-11-01 / 발행: 2026-11-02

> 이번 파일은 기존 Canva 21페이지의 완전한 전사본이 아니다. 기존 작업 기록에서는 전체 슬라이드 본문을 확보하지 못했으므로 아래 공식 발표를 확인해 웹 게시용으로 새로 작성했다. 기존 Canva 자료는 관련 자료로 연결한다. 확인한 분야와 확인하지 못한 분야를 구분한다.

## 이번 주 핵심

1. AI 학습에 대한 웹사이트 운영자의 의사 표시를 단순화하려는 움직임이 발표됐다. 시행 완료와 발표는 구분해야 한다.
2. AI와 업무 시스템의 연결은 답변 생성에서 권한을 가진 실행으로 확장되고 있다.
3. XR 사례는 콘텐츠와 작업 화면을 공간으로 확장하는 흐름을 보여준다. 신규 기기 구매보다 수업 설계상의 의미를 먼저 검토한다.
4. 장비별로 해당 주간에 새 릴리스가 없었다고 단정하지 않는다. 이번 확인에서 날짜와 내용을 함께 검증하지 못한 분야는 별도 표시한다.

## 1. 웹 콘텐츠의 AI 학습 선호를 표현하는 공통 신호

**공식 발표 / OpenAI / 2026-10-30**

OpenAI는 웹사이트가 생성형 AI 학습에 관한 선호를 표현하는 공통 robots.txt 신호를 존중하겠다고 발표했다. 여러 공급자마다 개별 규칙을 관리하는 부담을 줄이는 것이 취지다. 발표문은 수개월 내 구현을 목표로 한다고 명시하며, 기존 크롤러 제어를 대체하지 않는다고 설명한다.

‘발표됐다’와 ‘이미 모든 서비스에서 강제 적용된다’는 다르다. 이 발표만으로 웹 콘텐츠의 사용이 법적으로 완전히 통제되거나 과거 학습 데이터가 삭제된다고 설명하지 않는다.

[공식 원문](https://openai.com/index/helping-websites-express-ai-training-preferences/)

### 교육·제작 해석

포트폴리오를 공개하는 일과 데이터 이용 선호를 표시하는 일을 구분해 설명할 수 있다. 학생에게 공개 여부, 출처, 수정 이력, 다운로드 범위를 함께 생각하게 한다. 공개 자료를 참고하는 사람도 원문 링크와 라이선스 확인 기록을 남기는 연습을 한다.

## 2. 업무 시스템과 연결되는 AI 실행

**공식 발표 / OpenAI·ServiceNow / 2026-10-28**

양사는 OpenAI 모델·에이전트와 ServiceNow 업무 흐름을 연결하는 협력 확대를 발표했다. 조직이 허용한 범위에서 관련 사건을 찾고 기록을 갱신하는 방식이 소개된다. 기존 규칙과 권한이 적용된다는 설명이 중요하다.

발표 기준 ServiceNow MCP 플러그인은 이용 가능하다고 안내됐으나 강화 기능은 2026년 말, 음성·보안·개발 관련 일부 기능은 2027년으로 계획되어 있다. 개인 ChatGPT 사용자가 모든 기업 기능을 곧바로 쓸 수 있다는 의미가 아니다.

[공식 원문](https://openai.com/index/openai-servicenow-partnership-expansion/)

### 바이브코딩 해석

사이트의 화면을 만드는 일과 데이터를 변경하는 권한은 별개다. EDU_PROJECT에 리포트를 추가할 때도 원문 파일, 목록 데이터, 본문 렌더링을 나누면 변경 지점을 파악하기 쉽다. 자동 등록을 도입하기 전 수동 파일 추가와 미리보기 검토를 먼저 안정화한다.

## 3. 공간형 화면과 XR 콘텐츠

**공식 발표 / Google / 2026-10-28**

Google은 Android XR 기반 유선 안경 XREAL AURA를 소개했다. 투명 렌즈로 주변을 보면서 앱을 배치하는 방식과 Gemini 연계를 설명한다. 발표문은 미국·캐나다·한국의 10월 28일 주문 시작, 일본의 11월 2일 주문 시작, 11월 중순 배송 개시를 안내한다. 대상은 18세 이상이며 호환 계정 등 조건이 있다. 주문 시작을 즉시 수령으로 혼동하지 않는다.

[공식 원문](https://blog.google/products-and-platforms/platforms/android/xreal-aura/)

### 수업 해석

이 사례는 AI가 화면 안의 문답을 넘어 관찰하는 공간과 화면의 맥락을 함께 다루려는 방향을 보여준다. 초등학생용 체험 장비로 곧바로 추천하지 않는다. 성인·대학생 수업에서는 실제 기기 구매 없이 공간형 정보 배치 스토리보드를 만들 수 있다. 긴 설명을 눈앞에 가득 띄우는 것과 필요한 순간에 한 단계만 안내하는 방식의 차이를 비교한다.

## 4. 모바일 ChatGPT 계정 전환

**공식 릴리스 노트 / OpenAI / 2026-10-30**

iOS·Android 앱에서 두 계정에 로그인한 상태로 전환하는 기능의 순차 배포가 안내됐다. 계정별 대화·메모리·설정·구독은 유지된다고 설명한다. 기능이 개인 앱에 표시되는지는 직접 확인해야 한다.

[공식 릴리스 노트](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

### 강사 준비 제안

실습 전 수업용 계정과 개인 계정, 현재 선택 계정과 공유 화면을 확인한다. 학생이 강사와 같은 메뉴를 보지 못할 경우 앱·계정·순차 배포 차이를 먼저 기록한다.

## 보유 장비에 적용하는 원칙

기준 장비는 xTool F1, Bambu Lab H2S·X2D이며 X2D에는 AMS 2개가 있다. H2S에 언급되지 않은 옵션은 가정하지 않는다. 새 출력 성능이나 장비의 소재 호환성을 이번 뉴스에서 검증한 것으로 표시하지 않는다.

다색 출력 과제는 슬라이싱 예상 시간·필라멘트 사용·색 교체 비용을 확인해 사전 출력 여부를 결정한다. F1에서 투명 아크릴 직접 커팅이나 레진·출력물의 레이저 가공을 검증 없이 제안하지 않는다. 레진 경화는 제품별 지침을 따르며 경화 시간을 수업 활동 시간과 별도로 잡는다.

## 수업 아이디어 1. AI 시안에서 출력 가능한 굿즈로

- 대상: 대학생·성인
- 활동: 60분, 출력 시간 별도
- 도구: 이미지 생성 도구, Inkscape, Bambu Studio
- 과정: 대상 정의 → 시안 비교 → 작은 요소·연결 확인 → SVG 정리 → 크기와 출력 구조 검토 → 슬라이싱 예상 비교
- 결과물: 출력용 후보 파일과 선택·수정 기록
- 사전 준비: 강사가 사용 버전과 기본 프로필을 점검하고 일정에 맞춰 출력한다. 구조 치수는 재료·모델·장비에 따라 테스트한다.

## 수업 아이디어 2. 소재를 더해 사용 경험 바꾸기

- 대상: 성인·대학생
- 활동: 도안·색 계획·조립 구상 50분, 출력·경화 별도
- 도구·재료: 사전 출력 프레임, 호환성이 확인된 아크릴 부품, 선택한 레진과 제품별 작업·보호 장비
- 과정: 출력물의 구조와 아크릴의 표면 효과 비교 → 레진 색·채움 계획 → 강사 안내에 따른 소량 테스트 → 경화 후 조립·관찰
- 결과물: 소재 결합 샘플과 재료·공정 기록 카드
- 사전 준비: 제품 안전자료·환기·보호구·경화 조건·소재 호환성을 확인한다. 미경화 레진 취급을 초등학생 활동으로 옮기지 않는다. 레진 도포 전 레이저 가공을 완료하며 재가공을 임의로 시도하지 않는다.

## 수업 아이디어 3. 리포트에서 포트폴리오 프로젝트로

- 대상: 대학생·성인
- 활동: 45분
- 도구: Markdown 편집기, 기존 EDU_PROJECT, Codex
- 과정: 공식 소식 하나 선택 → 사실과 해석 분리 → 출처·날짜 작성 → 파일 등록 → 목록·모바일·링크 확인
- 결과물: 출처가 있는 웹 리포트와 내가 수정한 부분 기록
- 사전 준비: 원본과 미리보기를 구분하고 기존 경로·디자인을 보존한다. 자동 배포는 기존 프로젝트 절차를 따른다.

## 강사용 읽기자료 — 주간 종합 브리핑

이번에 확인한 공식 발표를 연결하면 AI의 활용 범위가 넓어질수록 콘텐츠 사용 의사, 업무 권한, 실제 제공 시점을 구분하는 능력이 중요해진다. 공통 크롤러 신호는 웹 제작자가 콘텐츠 이용 선호를 어떻게 표현할지 묻고, 기업 업무 통합은 누가 어떤 데이터를 읽고 바꿀 수 있는지 묻는다. XR은 디지털 정보를 사람의 생활공간에 어떻게 배치할지 질문을 넓힌다.

이 흐름을 메이킹 수업에 적용할 때는 새 제품을 많이 소개하는 것보다 학습자의 판단 기록을 남기는 편이 유용하다. AI로 만든 이미지를 제작 파일로 바꿀 때 사라지는 특징, 실제 재료에서 지켜야 할 구조, 출력 후 수정한 부분, 사용자에게 설명할 근거를 남긴다. 결과물과 함께 그 판단을 웹페이지에 기록하면 포트폴리오의 내용이 구체화된다.

성인 상품화 수업에서는 AI가 문구를 써줬는지보다 실제 소재·치수·사용 조건이 맞는지 확인하는 과정이 중요하다. 레진·아크릴·출력물을 결합하는 작업도 시각 효과만 보여주지 않고 공정 순서와 제품 조건을 기록한다. 이 파일의 수업 아이디어는 공식 발표의 사실과 구분한 편집자의 제안이며 새로운 재료 성능이나 안전성을 검증한 실험 보고서가 아니다.
