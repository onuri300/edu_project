# 리빙랩 PDF 교안

이 폴더에 `001_AI 음악 만들기.pdf`처럼 **세 자리 번호_과목명.pdf** 형식으로 실제 PDF를 넣으세요.
첫 밑줄 앞 번호로 정렬하며 이후 문자열은 공백·밑줄을 그대로 과목명으로 표시합니다.
예: `002_우리말_클리커 활동.pdf` → `우리말_클리커 활동`

소문자 `.pdf` 확장자를 사용하세요. 잘못된 파일명·PDF가 아닌 파일은 빌드 로그에 제외 사유가 출력됩니다.
같은 번호는 파일명순으로 정렬되므로 번호를 중복하지 않는 것을 권장합니다.
자료는 공개되므로 공개 가능한 PDF만 넣으세요.
