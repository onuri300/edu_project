# Onuri 공통 UI 개편 — 2026-11-03

Bootstrap의 간격·폼·버튼·카드 체계를 참고한 중립적 디자인입니다. Bootstrap 라이브러리를 추가하지 않고 기존 페이지의 클래스·기능·주소를 유지했습니다.

- 흰색/회색 바탕, 진한 본문, 절제된 파란 포인트. 기존 이미지는 그대로 사용.
- 공통 light/dark 토큰, 작고 일관된 모서리, 얇은 경계, 최소 그림자.
- 시작 화면은 이미지 중심 소개 + 메뉴 데이터에서 자동 생성하는 콘텐츠 컬렉션. 목록/주소를 HTML에 중복 작성하지 않음.
- 왼쪽 메뉴는 흰색 목차 레일로 정리. 접기/펼치기 및 모바일 서랍 유지.
- 뉴스레터·교안·센터·메이커·게임에 공통 토큰/폼/이미지/버튼 스타일 적용.
- 로그인, 공개 교안, 상세 새로고침, Markdown/PDF 다운로드, 새 탭의 헤더 제외 기능 유지.

## 관리
- 공통 디자인: common/css/common.css 마지막 Onuri UI 구역.
- 시작 화면 골격: index.html. 컬렉션 카드 동작: common/js/index.js.
- 개별 페이지의 기능 전용 CSS는 기존 파일을 사용하고, 색/표면은 공통 변수로 관리.
