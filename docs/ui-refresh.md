# Onuri 공통 UI 개편 — 2026-11-03

Bootstrap의 간격·폼·버튼·카드 체계를 참고한 중립적 디자인입니다. Bootstrap 라이브러리를 추가하지 않고 기존 페이지의 클래스·기능·주소를 유지했습니다.

- 흰색/회색 바탕, 진한 본문, 절제된 파란 포인트. 기존 이미지는 그대로 사용.
- 공통 light/dark 토큰, 작고 일관된 모서리, 얇은 경계, 최소 그림자.
- 시작 화면은 이미지 중심 소개 + 메뉴 데이터에서 자동 생성하는 콘텐츠 컬렉션. 목록/주소를 HTML에 중복 작성하지 않음.
- 왼쪽 메뉴는 흰색 목차 레일로 정리. 접기/펼치기 및 모바일 서랍 유지.
- 뉴스레터·교안·센터·메이커·게임에 공통 토큰/폼/이미지/버튼 스타일 적용.
- 로그인, 공개 교안, 상세 새로고침, Markdown/PDF 다운로드, 새 탭의 헤더 제외 기능 유지.

## 관리
- 공통 디자인: common/css/common.css 마지막 Onuri UI 구역.
- 시작 화면 골격: index.html. 컬렉션 카드 동작: common/js/index.js.
- 개별 페이지의 기능 전용 CSS는 기존 파일을 사용하고, 색/표면은 공통 변수로 관리.

## 검증
- Node 테스트 29개, 배포용 빌드 성공.
- 실제 Edge에서 11개 메뉴 페이지 순회 및 390px 모바일 가로 넘침 없음.
- 로그인·홈 카드 생성·밝은/다크 테마 동기화 확인, 페이지 JavaScript 오류 없음.
- 화면 검토 자료: .work/report-qa/ui-*.png (업로드 제외).

## 상단 메뉴 — 2026-11-03
- 왼쪽 내비게이션을 공통 헤더의 드롭다운 메뉴로 이동했습니다.
- 기존 홈페이지의 소개·컬렉션 카드는 그대로 전체 메뉴 역할을 합니다. 헤더의 전체 메뉴는 이 홈으로 복귀하며 별도 사이트맵 페이지는 없습니다.
- 모바일은 헤더의 메뉴 아이콘으로 동일한 분류/하위 메뉴를 펼칩니다.
- 밝게/어둡게 텍스트를 삭제하고 해·달 아이콘과 접근성 이름을 유지합니다. 로그아웃 아이콘은 달 오른쪽에 표시되며 로그인 전에는 숨깁니다.
- 변경: index.html, common/js/index.js, common/js/common.js, common/css/common.css.
- 검증: 테스트 29개, 배포 빌드, 실제 Edge에서 데스크톱·390px 모바일 내비게이션/전체 메뉴 복귀/테마/로그아웃 통과.

## 가로형 헤더·푸터 — 2026-11-03
- 참고: https://tolllee.github.io/haebom/#home 의 로고 보조문구/가로 메뉴와 짙은 2열 푸터 구성.
- Onuri 로고·아이콘 메뉴·중립 팔레트는 유지하고 헤더에 LEARN · CREATE · SHARE 보조 문구 추가.
- 본문의 최대 폭과 분리하여 헤더·푸터는 뷰포트 전체 너비, 좌우 여백은 화면 크기에 맞게 24~88px 유동 적용.
- 푸터는 홈의 본문 컨테이너 밖으로 이동. 소개/메시지/전체 메뉴/맨 위로/저작권 배치, 모바일은 세로 정렬.
- PC 헤더 높이 80px, 모바일 72px로 로그인·앱 높이·메뉴 펼침 위치 동기화.
- 테스트 29개·빌드 성공, 실제 Edge에서 2560px 헤더/푸터 너비 일치 및 메뉴/아이콘 비겹침, 390px 모바일 줄바꿈 확인.

## 로그인·테마 캐시 점검 — 2026-11-03
- 로컬 및 온라인 암호화 메뉴 모두 기존 로그인으로 복호화됨. 비밀번호 변경 없음.
- 온라인 common.js에는 테마 텍스트가 없으며 로컬과 일치. 이전 캐시 혼합 가능성에 대비해 배포 HTML의 CSS/JS URL에 파일 내용 해시를 붙임.
- version-assets.mjs는 기존 배포 빌드에서 자동 호출. 파일이 바뀌면 URL도 바뀌며 저장소 하위 경로 유지.
- 이전 테마 스크립트의 label span도 공통 CSS에서 숨김. 접근성 aria-label과 툴팁은 유지.
- 로그인 성공 후 화면 초기화 오류는 비밀번호 오류와 구분해 안내.
- 테스트 30개 및 배포 빌드 통과. 비밀번호/인증 정보는 업로드 파일에 추가하지 않음.

## 헤더 중앙 정렬·기타 공개 — 2026-11-03
- 헤더 배경은 전체 너비, 로고·메뉴·아이콘은 최대 1280px 중앙 행으로 정렬. 푸터의 전체 너비 유지.
- page_etc/의 HTML은 공통 인증 규칙에서 공개 처리. 현재 센터 소개·성인 MBTI·어린이 MBTI 모두 로그인/부모 창 없이 접근 가능.
- 다른 비공개 페이지의 기존 인증 규칙은 유지.
- 테스트 31개·빌드 성공. 실제 Edge에서 2560px 중앙 배치, 기타 3개 페이지 비로그인 직접 접속·새 탭·새로고침, 모바일 메뉴/로그아웃 확인.

## 페이지 정보·푸터 내용 정렬
배경은 전체 너비를 쓰고, 페이지 제목/새 탭 버튼/푸터의 Onuri와 메시지는 헤더의 1280px 중앙 영역(안쪽 24px)에 맞춤. 2560px 화면에서 헤더 로고의 시작선·페이지 정보 시작선·푸터 시작선의 일치와 배경 전체 너비를 브라우저로 확인. 모바일은 14~20px 여백. 떠 있는 새 탭 버튼도 같은 우측 기준 적용.
