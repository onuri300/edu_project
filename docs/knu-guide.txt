====================================================================
 경남대학교 3D창의공작센터 웹페이지 — 사용 가이드
====================================================================

이 페이지는 「2025 창원 평생교육 박람회 · 내일의 학교 성과발표회」
체험부스에서 QR코드로 연결해 보여줄 수 있도록 제작한 소개
페이지입니다. PC와 모바일 화면 비율에 맞춰 자동으로 레이아웃이
바뀌며, 사진은 원본 크기와 상관없이 자동으로 비율이 맞춰집니다.


1. 폴더 구조
--------------------------------------------------------------------
    knu-3dcenter/
    ├── index.html      ← 웹페이지 본체
    ├── 가이드.txt       ← 지금 보고 있는 안내 파일
    └── images/          ← 사진을 넣는 폴더

index.html를 더블클릭하면 브라우저에서 바로 확인할 수 있습니다.
실제 행사에서 QR코드로 접속하려면, 이 폴더를 웹 호스팅
서비스(학교 홈페이지 서버, GitHub Pages, Netlify 등)에 올린 뒤
그 주소로 QR코드를 만들어야 합니다. (아래 6번 참고)


2. 사진 넣는 방법
--------------------------------------------------------------------
images 폴더 안에 아래 파일 이름 그대로 사진을 넣어주세요.
사진이 없으면 점선 원(+) 모양의 안내 placeholder가 자동으로
표시되고, 사진을 넣으면 이미지 비율이 자동으로 박스에 맞춰
꽉 채워집니다 (원본 사진의 가로세로 비율이 달라도 상관없습니다).

  images/hero-main.jpg        센터 대표 사진 (첫 화면 큰 사진)
                               권장 비율 4:3 (예: 1200×930px)

  images/gallery-01.jpg ~ gallery-08.jpg
                               작품 갤러리 사진 8장
                               정사각형에 가까운 사진을 추천
                               (예: 1200×1200px)

  images/manager.jpg          담당자 프로필 사진 (원형으로 표시)
                               권장 비율 1:1 (예: 600×600px)

사진이 8장보다 적거나 많다면, index.html에서 <!-- CARD --> 형태로
되어있는 <div class="g-item">...</div> 블록을 복사하거나 삭제해서
개수를 조절하면 됩니다.


3. 꼭 확인하고 채워 넣어야 할 정보 (대괄호 [ ] 부분)
--------------------------------------------------------------------
index.html을 메모장이나 VS Code로 열어 아래 항목들을 실제 정보로
바꿔주세요. 대괄호까지 지우고 내용만 입력하면 됩니다.

  히어로 영역
  ────────────────────────────────────────────
  [6]종+ / [500]+ / [30]+  → 보유 장비 수, 누적 이용 학생 수,
                              운영 프로그램 수 등 실제 수치로 교체
                              (정확한 수치가 없다면 "다수", "여러" 등
                              문구로 바꿔도 좋습니다)

  체험부스 안내 (id="booth")
  ────────────────────────────────────────────
  [ ]일 ([ ]요일) [ ]:00–[ ]:00   → 실제 행사 날짜·시간
  [행사장 이름] [부스 번호]번 부스  → 실제 행사장 이름과 부스 번호
  체험 프로그램 4개 항목            → 실제로 운영할 체험 내용으로 수정

  오시는 길 (id="location")
  ────────────────────────────────────────────
  [ ]층 3D창의공작센터              → 제4공학관 내 정확한 층수/호실
  운영시간 [09:00]–[18:00]          → 실제 운영시간
  담당자 [담당자 이름] / [직함]     → 실제 담당자 정보
  전화 [055-000-0000]               → 센터 직통 전화번호
  이메일 [email@kyungnam.ac.kr]     → 센터 문의 이메일

  ※ 주소(경상남도 창원시 마산합포구 경남대학로 7, 제4공학관)와
    경남대학교 대표전화(055-245-5000)는 공식 정보를 반영해 이미
    입력해 두었습니다.


4. 지도 영역
--------------------------------------------------------------------
현재 구글 지도가 "경남대학교 제4공학관" 주소로 자동 표시되도록
연결되어 있어 별도 설정 없이 그대로 사용할 수 있습니다.
"네이버 지도로 보기" / "카카오맵으로 보기" 버튼은 클릭하면 해당
지도 앱(또는 웹사이트)에서 같은 위치를 검색해 보여줍니다.

정확한 건물 내 위치(예: 몇 층 몇 호)를 더 명확히 안내하고 싶다면,
addr-card 영역의 주소 문구에 층수·호실을 추가로 적어주세요.


5. 색상이나 문구를 바꾸고 싶다면
--------------------------------------------------------------------
index.html 상단 <style> 안, ":root { ... }" 부분에서 전체 색을
한 번에 바꿀 수 있습니다.

  --navy    : 메인 브랜드 컬러 (기본: 경남대 KNU BLUE 계열)
  --accent  : 포인트 컬러 / 버튼 색 (기본: 활기찬 오렌지)
  --sky     : 옅은 배경 톤

디자인 컨셉은 "신뢰감 있는 대학 브랜드 블루 + 눈에 띄는 오렌지
포인트"입니다. 대학 공식 상징색 매뉴얼상의 정확한 헥스코드를
확인하실 수 있다면 --navy 값을 그 코드로 교체해 더 정확한 브랜드
컬러를 사용하실 수 있습니다.


6. QR코드 만들기
--------------------------------------------------------------------
이 파일 자체에는 QR코드가 포함되어 있지 않습니다. QR코드는
"완성된 웹페이지의 실제 인터넷 주소(URL)"가 있어야 만들 수
있기 때문입니다. 아래 순서로 진행해 주세요.

  1) knu-3dcenter 폴더(index.html + images 폴더)를 웹 호스팅에
     업로드합니다. (학교 홈페이지 서버, 또는 GitHub Pages,
     Netlify 같은 무료 호스팅도 가능)
  2) 업로드 후 발급된 주소(예: https://3dcenter.kyungnam.ac.kr)를
     복사합니다.
  3) 네이버 QR코드 생성기, 네이버 큐알 코드 스캐너 등 무료 QR
     생성 서비스에 그 주소를 입력해 QR코드 이미지를 내려받습니다.
  4) 부스 배너나 안내판에 QR코드를 인쇄해 부착합니다.


7. 완성 후 제출/배포 방법
--------------------------------------------------------------------
knu-3dcenter 폴더 전체(index.html + images 폴더)를 압축(zip)해서
보관하거나 웹 서버에 업로드하세요. index.html만 따로 옮기면
사진이 표시되지 않으니 반드시 images 폴더와 함께 이동해야 합니다.
