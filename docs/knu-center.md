# 경남대학교 3D창의공작센터 페이지 관리

대상: page_etc/knu-makerspace.html

특정 행사 홍보 화면을 센터의 상설 소개 페이지로 변경했습니다.
센터 소개 → 교육·지원 → 제작 분야 → 이용 절차 → 센터장·문의 → 공식 정보 순서로 구성합니다.
기존 박람회·부스·미정 날짜·임의 통계·검증되지 않은 장비 상세 사양·무료/무예약 이용 문구는 제거했습니다.

## 표시 정보와 근거

| 내용 | 근거 |
|---|---|
| 3D 제작·Blender 교육, 3D프린터·레이저 장비 활용, 지역 진로교육 | 경남대학교 RISE 조직·기능 안내 |
| 2015 제작 장비 기반, 2018 메이커스페이스 운영기관 선정 | 산학협력단의 메이커스페이스 선정 기사 |
| 2025 협업형 메이커스페이스 참여 | 경남대학교 공식 뉴스 |
| 센터장 이학선 교수 | 사용자 지정, 경남대학교 2025 공식 기사에서도 확인 |
| 이용 문의 055-249-2500 | 산학협력단 부속기관 안내 |
| 제4공학관 1층 | 경남대학교 공식 교육 공지 |

출처 링크는 페이지 하단 공식 정보 영역에 함께 제공합니다. 확인일: 2026-11-01.
현재 운영시간·요금·예약 방식·장비 상세 모델은 단정하지 않고 센터 문의로 안내합니다.
제작 활동의 대표 그림은 AI 일러스트이며 실제 센터 내부 사진으로 설명하지 않습니다.

## 첨부 이미지

- images/knu-center-logo.png: 사용자가 제공한 센터 로고 원본. 페이지 메뉴에 사용합니다.
- images/knu-manager-character.png: 사용자가 제공한 캐릭터 원본. 센터장·문의 카드의 안내 이미지로 사용합니다.
- 상반신 표시는 common/css/pages/knu/index.css의 .director-portrait에서 처리합니다. 원본 파일을 자르거나 변형하지 않고 화면에서만 상반신을 보여줍니다.
- images/knu-makerspace-hero.png: 기존 메이킹 대표 일러스트. 같은 파일명으로 교체할 수 있습니다.

모든 공통 헤더·로그인·테마 기능은 유지합니다. 기타 → 경남대학교 메이커스페이스 메뉴로 접속합니다.
