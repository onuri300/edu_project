# 이미지 생성 프롬프트 기록

내장 image_gen 도구로 네 종류의 완성 이미지를 생성했습니다. 각 테마의 대표 파일은 images 폴더에서 관련 페이지가 공유합니다. 원본 출력은 Codex generated_images에 보존했습니다.
장식용 AI 일러스트로서 실제 시설·인물·수업 결과물 사진을 대체해 사실을 주장하지 않습니다.

## Learning — 로그인·자료실·편집기

Landscape 3:2, no text, no letters, no logos, no watermark. Polished welcoming adult education visual, not childish. Output a single finished raster image.
